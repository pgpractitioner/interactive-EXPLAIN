# postgres-mistakes

Common PostgreSQL mistakes, and how to avoid them.

This repo is a fork of [pgcraftsman/postgres-mistakes](https://github.com/pgcraftsman/postgres-mistakes). I keep it as part of my notes while learning PostgreSQL.

## What is this?

Most database problems come from the same few mistakes. This repo collects them in one place so you can spot them early, understand why they hurt, and fix them.

## How to use it

1. Clone the repo:
   ```bash
   git clone https://github.com/pgpractitioner/postgres-mistakes.git
   cd postgres-mistakes
   ```
2. Read through the examples one by one.
3. Try them on a test database, never on production.
